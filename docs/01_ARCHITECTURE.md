# System Architecture: TechPulse Intelligence

## 1. High-Level Map
TechPulse Intelligence is an autonomous daily tech and cyber intelligence platform. It aggregates high-signal telemetry across cybersecurity, artificial intelligence, open-source developer tooling, and macro tech headlines, analyzes it using Google Gemini with strict schema validation, and distributes it to both a Git-backed streak archive and a modern web dashboard.

## 2. Core Modules & Boundaries

### 2.1 Ingestion Layer (src/collectors/)
- **cve_collector.py**: Queries CISA KEV and GitHub Security Advisory REST endpoints. Extracts active exploits, affected components, and official remediation advice.
- **i_collector.py**: Queries Hugging Face Daily Papers and Model Hub APIs. Filters for breakthrough architectures, open-weights, and community upvotes.
- **github_collector.py**: Queries GitHub Search API for high-velocity newly created repos (< 7-14 days old). Captures rising dev stars and tools.
- **
ews_collector.py**: Queries Hacker News Firebase API for top curated tech stories and architectural discussions.
- **Boundary Rule**: Collectors must ONLY fetch and normalize external data. They perform zero business logic or markdown formatting.

### 2.2 Intelligence & Synthesis Layer (src/analyzer/)
- **models.py**: Pydantic v2 schemas (DailyReport, CveItem, AiBreakthrough, TrendingTool, TechNewsItem).
- **gemini_analyzer.py**: Uses google-genai SDK with strict JSON schema mode (gemini-2.5-flash). Enriches raw signals with impact assessments, threat levels, and executive takeaways.
- **allback_analyzer.py**: Deterministic offline synthesizer ensuring zero-failure runs if API quota or internet degrades.
- **Boundary Rule**: The analyzer produces a validated DailyReport object and never writes directly to disk or calls git.

### 2.3 Storage Layer (data/ & eports/)
- **data/YYYY/MM/YYYY-MM-DD.json**: Machine-readable JSON consumption endpoint for the web dashboard.
- **eports/YYYY/MM/YYYY-MM-DD.md**: Human-readable Markdown document committed for GitHub repository viewers.
- **data/archive_index.json**: Chronological index enabling O(1) archive navigation.

### 2.4 Distribution Layer (src/git_manager/ & .github/workflows/)
- **streak_engine.py**: Manages human-like randomized execution jitter (15–120 min delay bounds), commits changes under configured user identity, and pushes to remote.
- **daily-intel.yml**: GitHub Actions serverless cron runner.

### 2.5 Web Application Layer (web/)
- **Next.js 14/15 App Router** + **Tailwind CSS**.
- Reads JSON static assets generated by the pipeline.
- Dark-mode cyber terminal aesthetic (Threat Radar, Paper Explorer, Tool Arsenal, Calendar Archive).

## 3. Data Flow Contract
1. **Raw Collection**: Collectors produce typed dictionaries matching ingestion contracts.
2. **Analysis**: Analyzer receives dict, constructs prompt + schema, validates against DailyReport.
3. **Serialization**: Validated DailyReport serialized to JSON and formatted to Markdown.
4. **Distribution**: Git manager commits data; Next.js builds/serves statically.
